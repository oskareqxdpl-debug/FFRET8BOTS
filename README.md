# Bot Panel (Fabric 1.21.4)

## Jak dostać gotowy .jar
1. Konto na github.com -> nowe repozytorium -> wrzuć CAŁĄ zawartość folderu (z `.github`).
2. Zakładka **Actions** -> zielony build -> **Artifacts** -> `botmod-jar`. Czerwony? Wklej mi log błędu.

## Instalacja
Fabric Loader 1.21.4 + Fabric API 0.119.2+1.21.4 + ten .jar w folderze `mods`.

## Obsługa
- Klawisz **K** albo przycisk **Boty** w menu głównym / pauzy.
- **Lista botów:** nick i IP (bez portu), „Dodaj bota”. Bot nie robi nic sam: nie loguje się, nie wysyła komend i nie ma anty-AFK. Do 3 botów.
- **Bot:** zakładki Konsola, Podgląd, GUI, Ruch.
  - **Podgląd -> Znacznik w grze:** nazwa i odległość bota rysują się na twoim ekranie, widać przez ściany, tylko ty. Bez OP.
  - **Podgląd -> Kamera bota:** twoja gra pokazuje widok z oczu bota (bot musi być w zasięgu renderowania). Wyjście: klawisz **J**.
  - **GUI:** hotbar, ekwipunek, prawy klik (kompas), okna serwera. **Ruch:** W/A/S/D, skok, obrót.
- Esc nie rozłącza botów, robi to tylko przycisk Rozłącz.
